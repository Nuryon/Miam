# MIAM V3 — Scanner amélioré

## Améliorations
- OCR français/anglais avec meilleure segmentation de page.
- Nettoyage du texte OCR.
- Séparation plus robuste entre ingrédients et étapes.
- Détection des lignes fusionnées par l'OCR.
- Numérotation automatique des étapes.
- Photo associée à la recette scannée quand sa taille le permet.
- Nouvelle fiche recette inspirée d'une mise en page éditoriale/magazine.
- Mise en page responsive mobile et desktop.
- Cache PWA versionné pour faciliter les mises à jour.

Pour obtenir le meilleur scan : page bien éclairée, photo prise de face, texte net et page entière visible.
